# 5 Idiots, 1000 Memories — UI Demo

Open `index.html` in a browser.

## Replace the placeholder images
All demo images are inside `assets/`.
You can replace them with your own photos. The easiest option is to keep the same filenames and use JPG/PNG files, then change the corresponding `.svg` extension in `index.html` to `.jpg` or `.png`.

## Included
- Responsive HTML structure
- CSS scrapbook/polaroid design
- Sticky browser-style header
- Animated scroll reveals
- Animated glowing journey route
- Hover animations
- Secret message wall: click "Leave a Memory"
- Video vault modal interactions
- Memory search
- Self-contained demo assets

No build tools are required.
