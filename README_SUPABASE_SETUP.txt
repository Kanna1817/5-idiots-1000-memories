SUPABASE DATABASE SETUP
========================

This version is connected to the Supabase project configured in script.js.
It uses the Supabase publishable key in the browser. Do NOT add a Supabase secret key to this project.

1) Open Supabase Dashboard > SQL Editor.
2) Run the SQL below exactly once.

create table public.memories (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(name) between 1 and 40),
  message text not null check (char_length(message) between 1 and 240),
  memory_date date,
  created_at timestamptz not null default now()
);

alter table public.memories enable row level security;

create policy "Anyone can read memories"
on public.memories
for select
to anon
using (true);

create policy "Anyone can add memories"
on public.memories
for insert
to anon
with check (
  char_length(name) between 1 and 40
  and char_length(message) between 1 and 240
);

grant select on public.memories to anon;
grant insert on public.memories to anon;

3) Open the website.
4) Click "Leave a Memory".
5) Add a name + memory and press "Save Memory".

WHAT THIS DOES
- Memories are stored in PostgreSQL through Supabase.
- Refreshing the page keeps the memories.
- The same memories can be loaded from other devices/browsers.
- This public setup allows anyone with the website to read and add memories.

SECURITY NOTE
The publishable key is intended for browser apps. Access is controlled by Postgres grants + Row Level Security. Never put a Supabase secret key in index.html or script.js.
